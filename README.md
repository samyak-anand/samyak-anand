### 📈 Hybrid FinBERT + LSTM Stock-Movement Forecasting

**Master's Thesis**

Developed a hybrid deep-learning framework combining **FinBERT-based financial sentiment analysis** with **LSTM time-series forecasting**.

* Processed financial news using transformer-based NLP
* Generated daily financial sentiment indicators
* Combined sentiment with historical market data and technical indicators
* Developed LSTM-based forecasting models
* Benchmarked against XGBoost, Random Forest, SVM and Logistic Regression
* Applied **SHAP** for model explainability
* Evaluated forecasting and directional performance

`Python` `FinBERT` `Hugging Face` `LSTM` `TensorFlow` `Keras` `Scikit-learn` `SHAP`

### 🩻 Pneumonia Detection & Segmentation

Developed an end-to-end **computer vision pipeline** using approximately 26,000 chest X-ray images from the RSNA Pneumonia Detection Challenge.

* Built U-Net, ResNet U-Net and MobileNet U-Net architectures
* Developed CNN-based pneumonia classification models
* Applied image preprocessing and augmentation
* Evaluated segmentation using IoU and Dice
* Evaluated detection/classification using mAP, F1 and AUC
* Built an interactive **Streamlit application** for inference and visualization

`Python` `PyTorch` `TensorFlow` `Keras` `U-Net` `Computer Vision` `Streamlit`
